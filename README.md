# nono-packs

Personal [nono] packs for sandboxing AI coding agents.

| Pack | Description |
| --- | --- |
| [claude-no-keychain] | Claude Code without macOS keychain access, based on `nolabs-ai/claude` |

Install a pack with `nono pull hackebrot/<pack>`. See each pack's README for
details.

These packs are maintained by me and are not affiliated with nolabs.
