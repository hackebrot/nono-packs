# nono-packs

Personal [nono] packs for sandboxing AI coding agents.

| Pack | Description |
| --- | --- |
| [claude-hardened] | Hardened Claude Code profile based on `nolabs-ai/claude`: no keychain access, sandboxed OAuth login, and tighter filesystem and environment access |

Install a pack with `nono pull hackebrot/<pack>`. See each pack's README for
details.

These packs are maintained by me and are not affiliated with nolabs.
