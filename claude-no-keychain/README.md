# claude-no-keychain

nono profile for Claude Code without macOS keychain access, based on the
`nolabs-ai/claude` profile.

`policy.json` and `bin/ensure-dirs.sh` are from [nolabs-ai/nono-packs]
(Apache-2.0). `policy.json` is modified to remove keychain access.

[nolabs-ai/nono-packs]: https://github.com/nolabs-ai/nono-packs
